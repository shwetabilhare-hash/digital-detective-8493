# Mission 1 - Know your computer

## 1. Task / objective

Explain how a computer receives input, processes information, produces output and stores results (IPOS). Identify hardware, software and computer-based systems around me.

## 2. Work completed

I traced one activity (typing and saving a document) through the IPOS stages, listed four hardware items and four software examples, and described three computer-based systems I see in everyday life.

## 3. Commands / tools used

No Terminal commands were needed for this mission. I used VS Code to write this README.

## 4. My understanding

### Task 1.1 - IPOS for typing and saving a document

| Stage | What happens in my example? | Hardware / component |
|---|---|---|
| Input | I press keys on the keyboard to type the text. | Keyboard |
| Processing | The CPU works on the key presses and the memory (RAM) holds the text while I work. | CPU and RAM |
| Output | The typed text appears on the screen. | Screen |
| Storage | When I press save, the document is written to storage so it stays after the computer is off. | SSD |

The activity moves from input (keyboard) to processing (CPU and RAM), then to output (screen), and finally to storage (SSD) when I save.
