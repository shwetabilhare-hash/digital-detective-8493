## 3. Commands / tools used

- python3 --version: checks which Python version is installed (Python 3.14.7).
- git --version: checks which Git version is installed (git version 2.50.1, Apple Git-155).
- cd: moves into a folder.
- mkdir: creates a new folder.
- touch: creates a new empty file.
- ls: lists the files and folders in the current location.
- open -a "Visual Studio Code" .: opens the project folder in VS Code.
- VS Code: the text editor I used to write the README files.

## 4. My understanding

A repository is a project folder whose changes are tracked by Git, and it can be stored online on GitHub. The structure is organised by mission so that each mission has its own folder, README and commit. This makes my work easy to review step by step.
